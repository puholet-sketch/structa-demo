# Structa · демо оргструктуры (Nordix)

Публичное демо кадрового реестра с оргструктурой.

**Live:** https://puholet-sketch.github.io/structa-demo/

## Важно

Данные **синтетические**: вымышленная группа компаний Nordix / Axiom FinTech / Клаудкор.  
Иерархия отделов и набор ролей типичны для IT-вендора в страховании, но **не являются** данными реального работодателя. Реальных ФИО нет.

## Возможности

- Дерево компаний и отделов
- Карточки сотрудников, фильтры, поиск
- Excel импорт/экспорт, печать PDF
- Локальное сохранение в браузере + «Сбросить демо»

## Пересборка seed

```bash
python scripts/build_demo_seed.py
```

Скрипт берёт только **форму** иерархии из приватного источника и подставляет вымышленные ФИО/юрлица.
